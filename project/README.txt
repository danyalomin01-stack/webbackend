Проект Drupal-coder + PHP backend

Как залить на учебный сервер:
1. Все файлы из архива загрузить в /otch/project/
2. Проверить, что загрузился скрытый файл .htaccess
3. Создать папку data, если ее нет, и дать права на запись:
   mkdir -p data
   chmod 777 data
4. Открыть: http://u82410.kubsu-dev.ru/otch/project/

Как работает:
- На главной странице обычный фронт Drupal-coder.
- Форма отправляется через fetch без перезагрузки.
- Если JS выключен, форма отправляется обычным POST.
- После отправки заявки сайт показывает логин, пароль и ссылку на профиль.
- Для редактирования теперь используется отдельная страница login.php, без браузерного окна Basic Auth.
- После входа открывается /profile/{id}, где можно изменить данные заявки.

API:
POST /api/profile — создать заявку.
PUT /api/profile/{id} — изменить заявку после входа.
